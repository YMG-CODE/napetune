# 初回公開時のソース確認

以下は初回公開用コピーの作成時点の記録です。現在の配布バイナリと対応ソースは[配布案内](../../docs/firmware.md)を参照してください。

- 選択したアプリソースはv6と比較済み。ライセンス注記と旧エンジン起動文言以外は同一。
- 同梱USBライブラリは開発版とバイト単位で同一。
- 未使用の旧エンジン・診断コードや個人用作業フォルダーは公開用コピーに未収録。
- 画像の適用条件と混在ソースの作品表現を[CONTENT_MANIFEST.json](../CONTENT_MANIFEST.json)に記載。
- 初回公開時のビルド結果は[BUILD_RESULTS.md](../BUILD_RESULTS.md)参照。
