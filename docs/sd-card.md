# SDカードの使い方

## 準備

本体のmicroSDスロットへ、M5Stackの使用環境で読み書きできるカードを挿入してから起動します。
カードの挿入・取り外しは電源を切って行ってください。
内蔵のSTORY・DEMOを起動するために、追加のゲームファイルをコピーする必要はありません。

現在のソースは、必要な保存フォルダーを起動時に自動作成します。
SDが認識できない場合もRAM上の状態で動きますが、ゲームの保存内容は電源を切ると保持されません。

## 保存先

| 保存するもの | 保存場所 |
|---|---|
| ゲームの状態・進行フラグ・装備等 | SDの`/napetune/system/save/save0.dat` |
| 前回のゲームセーブ | 同じフォルダーの`save0.bak` |
| 書き込み途中の一時ファイル | 同じフォルダーの`save0.tmp` |
| ゲームコンフィグ・キー機能・自動操縦設定 | M5Stack本体内のNVS |
| GLASS2案内用の前回キーマップ | M5Stack本体内のNVS |
| Nape Pro本体のキー割り当て | Nape Pro側の設定 |

SDのセーブとゲームコンフィグは別です。SDを交換しても、本体内のキー設定や前回キーマップは残ります。
セーブ形式は開発中のため、更新前にバックアップしてください。保存項目があっても、全モードが任意の場面から再開できるわけではありません。

## バックアップと復元

1. メニューに戻り、保存処理が終わってから本体の電源を切ります。
2. SDをPCで開き、`napetune`フォルダーを丸ごとコピーします。
3. 復元時は電源を切った状態で、同じフォルダー構成に戻します。

起動時は`save0.dat`を検証して読み込み、無効な場合は`save0.bak`を試します。
両方とも読み込めない場合は初期状態になります。`save0.tmp`を通常のセーブとして扱うことはありません。
本体内の設定とNape Pro側の設定は、このSDバックアップには含まれません。

## 任意の外部画像

LOUNGEには、次の場所から外部PNGを読む処理があります。これはSD保存とは別の任意機能です。
ファイルがない場合は内蔵の表示へフォールバックします。

- 歩行画像：`/napetune/lounge/iz/`内の`down_0.png`、`down_1.png`、`left_0.png`、`left_1.png`、`right_0.png`、`right_1.png`、`up_0.png`、`up_1.png`。8枚一式で読み込みます。
- 表情画像：`/napetune/lounge/iz/portraits/`内の`thinking.png`、`surprised.png`、`smile.png`、`slight_smile.png`、`normal.png`、`angry.png`、`sad.png`、`serious.png`、`shy.png`、`joy.png`。

外部ストーリーパックをSDへ置くだけで読み込める仕様ではありません。
作品画像の条件は[作品素材の利用条件](../prototype/CONTENT_LICENSE.md)を参照してください。
